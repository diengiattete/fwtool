Yêu cầu Trình Duyệt Web

Ứng dụng sử dụng chuẩn Web Serial API. Hãy chạy trên Google Chrome, Microsoft Edge, hoặc Opera trên máy tính.

Quy Trình Nạp Firmware Chuẩn:

  1. Cắm mạch ESP qua cáp USB vào máy tính.
  2. Nút KẾT NỐI & ĐỌC CHI TIẾT CHIP ➔ Hệ thống sẽ đọc thông số chi tiết và lấy dữ liệu cập nhật từ mạng.
  3. Chọn duy nhất 1 file `.bin` firmware.
  4. Bấm nút BẮT ĐẦU NẠP FIRMWARE và đợi 100%.
