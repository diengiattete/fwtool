Hướng Dẫn Nạp Single-File Firmware

Firmware hệ thống đã được tự động nạp ngầm sẵn sàng

Yêu cầu Trình Duyệt Web

Ứng dụng sử dụng chuẩn Web Serial API. Hãy chạy trên Google Chrome, Microsoft Edge, hoặc Opera trên máy tính.

Quy Trình Nạp Firmware Chuẩn:

  1. Cắm mạch ESP qua cáp USB vào máy tính.
  2. Bấm nút KẾT NỐI & ĐỌC CHI TIẾT CHIP.
  3. Hệ thống tự động nhận diện dung lượng: $\ge$2.5MB chọn Offset `0x0`, nhỏ hơn chọn `0x10000`. Bấm BẮT ĐẦU NẠP FIRMWARE.
  4. Sau khi nạp xong, hệ thống sẽ tự động ngắt kết nối. Bạn có thể gạt công tắc để bật tính năng tự động kết nối lại nếu muốn.
